# 💼 Карьерный навигатор

**Карьерный навигатор** — это веб-ресурс, объединяющий абитуриентов, вузы и работодателей с целью упростить выбор образовательной траектории и трудоустройство.

---

## 🔐 Система авторизации и регистрации (JWT)

- Регистрация и авторизация пользователей
- Интеграция с защищёнными протоколами
- Восстановление пароля и подтверждение email-адреса
- Поддержка входа через социальные сети *(дополнительная задача)*

---

## 🧭 О проекте

Проект создаётся с целью помочь:

- 📚 Абитуриентам — осознанно выбрать будущую профессию
- 🎓 ВУЗам — эффективнее формировать образовательные программы
- 🏢 Работодателям — находить специалистов с нужными навыками

---

## 🛠 Основной функционал

### Для абитуриентов:
- Просмотр востребованных профессий
- Информация об экзаменах и вузах
- Прохождение профориентационного теста

### Для вузов:
- Размещение направлений подготовки
- Публикация экзаменов и компетенций выпускников

### Для работодателей:
- Публикация требований к специалистам
- Информация о нужных экзаменах и компетенциях

## 🌟 Преимущества

- 🎯 Осознанный выбор профессии
- 🎓 Улучшение подготовки специалистов
- 🤝 Эффективный подбор кандидатов

## 🚀 Установка и запуск

### 1. Клонируй проект:
   git clone https://github.com/DeaforK/career-navigator.git
   cd career-navigator

### 2. Установи зависимости:

    cd client
    npm install

    cd ../server
    npm install


    Создай файл .env в папке server и настрой переменные окружения.

### 3. Запусти сервер и клиент:

    ## Сервер:
        cd server
        npm run dev
    ## Клиент:
        cd client
        npm run dev

## 🧩 Технологии

Frontend: Nuxt 3 (Vue.js)

Backend: Node.js, Express

Auth: JWT, Email Verification

DB: MySQL

Dev Tools: JavaScript, REST API
